A cloud-based platform for disaster, weather and location intelligence.

**Built with**

`React.js` `TypeScript` `Node.js` `Express.js` `Kotlin` `PostgreSQL`

**What I built**

- Integrated **GDACS, NASA EONET, Open-Meteo and OpenStreetMap** for real-world environmental and geographic data.
- Engineered a **risk assessment and relocation engine** for affected-region analysis.
- Generated data-driven relocation candidates using geographic and facility information.
- Developed a **native Android application** with location-based alerts and interactive maps.
- Added **Room offline caching** to maintain access to recently synchronized data without connectivity.
